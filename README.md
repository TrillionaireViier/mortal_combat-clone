# Shadow Arena — Godot 4

A small, asset-free 2D fighting game prototype built with Godot 4. Two players can fight locally on one keyboard. The fighters and moonlit arena are drawn in code, so no downloads or extra assets are needed.

## Run

1. Install Godot 4.
2. Import `project.godot` from this folder.
3. Press **F6** to run the current scene or **F5** to run the project.

## Controls

| Player | Move | Jump | Punch | Kick |
| --- | --- | --- | --- | --- |
| Player 1 | A / D | W | F | G |
| Player 2 | Left / Right arrows | Up arrow | J | K |

Press **Enter** or **Space** after a knockout to restart the round.
